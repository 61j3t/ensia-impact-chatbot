Le GPU Passthrough est une technologie qui permet d’attribuer une carte graphique physique dédiée à une machine virtuelle. Cela garantit des performances GPU quasi natives ( physique ) pour les applications exigeantes comme l’IA, le rendu 3D ou le calcul scientifique.
• GPU partagé : les ressources d’une même carte graphique sont utilisées par plusieurs utilisateurs en même temps.
• GPU dédié (Passthrough) : une carte graphique complète est attribuée à un seul client. Toutes les ressources du GPU sont exclusivement réservées à cet utilisateur, sans partage avec d’autres, garantissant des performances stables, constantes et optimales.
